Evals

An eval is a fixed set of test cases with known answers. The same set is run again after every change, so the result shows what the change did.

A pass rate is only worth what its answers are worth: 90% on cases written to have one right answer and 90% agreement with another model are different claims. Each eval below says which one it is.
